# Patents

Patents (SureChEMBL-oriented) search finds patent chemistry similar to a query so you can inspect public IP-adjacent structures.

## Goal

Surface patented neighbors that may inform freedom-to-operate brainstorming or scaffold awareness (not legal advice).

## When to use

Use when exploring whether related chemotypes appear in patent literature similarity space.

## Inputs / scope

Network-backed patent chemistry search from a query structure/SMILES as required by the dialog; results can be added to the table.

## Options

- **Query structure** / **similarity** controls.
- **Results** - SureChEMBL-style patent chemistry hit list.
- **Add to table** - import selected patent molecules.
- **Metadata** - patent refs and related fields when provided.

## Workflow

1. Open **Patents** from **External**.
2. Provide the query molecule.
3. Review similar patent chemistry hits.
4. Add relevant structures for deeper in-app comparison.

## Use cases

- Check whether a scaffold is crowded in patent space.
- Collect example claimed analogs for SAR discussion.
- Compare patent neighbors via in-app FP similarity next.

## Tips and limits

Similarity hits are not a legal clearance. Patent structure extraction can be imperfect. Always follow up in primary patent sources for decisions that matter.
